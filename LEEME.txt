PARA SUBIR A GITHUB
1. Descomprime el ZIP.
2. Sube index.html, style.css, mobile.css, app.js, .nojekyll y la carpeta assets a la raíz de tu repositorio. Conserva la carpeta assets con todas sus imágenes.
3. Activa GitHub Pages para publicar desde la rama que contiene los archivos y la carpeta raíz.
4. Abre el enlace que GitHub Pages te proporcione.

No requiere instalación ni compilación. También puedes abrir index.html en tu navegador para revisar la tarjeta.
